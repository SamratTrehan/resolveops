# Trajectories

Historical trajectories are immutable under `trajectories/baseline/<run-id>/` and `trajectories/resolveops/<run-id>/`.

For a judge, inspect input summaries, deterministic tool calls/results, the EvidenceBundle, proposed draft, verifier decision, any revision, runtime, retries, and final result. `resolveops-phase5a-001/CASE-003-*` shows Investigator -> Resolver -> Verifier -> Resolver revision and the remaining conservative camera limitation. `CASE-001-*` is an approved-without-revision example. Phase 5B safety metadata appears on future/demo final-stage trajectories as a human checkpoint, not an agent decision.
